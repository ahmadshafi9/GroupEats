# Contributing to GroupEats

Thanks for your interest in contributing. Here’s how to get started.

## How to contribute

1. **Open an issue** (optional but helpful) — Describe the bug or feature so we can align before you code.
2. **Fork the repo** — Use the “Fork” button on GitHub.
3. **Clone your fork** — `git clone https://github.com/YOUR_USERNAME/GroupEats.git`
4. **Create a branch** — `git checkout -b feature/your-feature` or `fix/your-fix`
5. **Make your changes** — Follow the existing code style (TypeScript, React Native/Expo).
6. **Test locally** — Run `npm install` and `npx expo start` to confirm nothing’s broken.
7. **Commit** — Use clear messages, e.g. `Add X` or `Fix Y`.
8. **Push** — `git push origin feature/your-feature`
9. **Open a Pull Request** — From your fork to the main repo. Describe what you changed and why.

## What we’re looking for

- Bug fixes, docs improvements, and small refactors are always welcome.
- For larger features (e.g. new screens or Firebase changes), open an issue first so we can discuss design and scope.

## Code and conduct

- Be respectful and constructive in issues and PRs.
- The project is MIT licensed; by contributing, you agree that your contributions will be under the same license.
